# 使用须知

1. **需要设置模型API**：这个项目基于llm agents，需要api，请在 "\consciousness_sim\config.json" 文件内添加api，可自行修改支持openai格式的模型。  
2. **注意**：由于此为试验项目，与AI对话框内模拟运行时的上下文管理系统不同，实测效果不稳定，仅供研究和学习使用。  
3. **建议**：建议直接使用提示词给一个专业级大模型启动模拟即可，例如Deepseek专家模式，思考模式打开。
---
1. **API setup required**: This project is based on LLM agents and requires APIs. Please add the API in the "\consciousness_sim\config.json" file, which can be modified to support OpenAI-format models.  
2. **Note**: As this is an experimental project, its context management system differs from that of AI chat simulations during runtime. Actual performance is unstable and is intended for research and learning purposes only.  
3. **Suggestion**: It is recommended to directly use prompt engineering to initialize a professional-grade large model simulation, such as activating Deepseek's expert mode with thinking mode enabled.
