# AICSE-AI-Consciousness-Simulation-Engineering  

## Using engineering methods to simulate a thinking system with partial conscious functions.  

**Implementation path**: Establish a two-layer structure of divergence and convergence layers. The divergence layer includes structures such as logical reasoning, criticism, emotional evaluation, association, motivation detection, and meta-cognition. The convergence layer includes selective synthesis to simulate attention, a consciousness stream writer to simulate working memory, and a language expressor to simulate linguistic output. This enables a thinking system with conscious functions such as introspection, doubt, perspective shifting, associative innovation, emotional experience, task planning, self-correction, continuous memory, and language refinement.  

**Usage methods**: 1. Direct simulation can be achieved using prompts in an AI dialogue interface (recommended). 2. Application through a multi-agent system.  

## File path:   
**Prompt**: Various version prompt words that can be directly sent to AI for use.  
**CSE**: Multi agent software application  


## 利用工程化的方法模拟有部分意识功能的思维系统。  

**实现路径**：建立发散层和收束层两层结构，发散层包括：逻辑推理、批判、情感评估、联想、动机检测、元认知等结构，收束层包括选择性合成模拟注意、意识流写入器模拟工作记忆、语言表达器模拟语言输出，可以实现具备自省、怀疑、观点转向、联想创新、情感感受、任务规划、自我纠偏、持续记忆、语言润色等意识功能的思维系统。  

**使用方法**：1. 可以在AI对话框使用提示词直接模拟。（建议） 2.使用多agent系统应用。  

## 文件路径：
**Prompt**: 各版本提示词，可直接发给AI使用
